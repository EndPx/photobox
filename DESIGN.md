# PhotoBox Design System

## Atmosphere

A compact print studio with dark oxblood upholstery and warm paper surfaces. The actual scrapbook frame is the focal point. The kiosk hero uses the existing commissioned shop artwork, and the editor places the print on a dark proofing surface.

## Typography

Use the existing Georgia display face for the studio identity and headings. Use system sans-serif for instructions, controls, and numbers. Keep headings compact during each paid step.

## Layout

Portrait is the primary iPad orientation. Keep navigation, the primary action, and the current task in the viewport. The editor has a stable print preview and one visible tool group. The admin shows one section at a time with transaction rows scrolling inside their ledger. Narrow phones may scroll vertically.

## Primitives

Use primary, secondary, and quiet buttons with visible focus, disabled states, and explicit selected states. The three editor tabs switch tools without moving the preview. Filter tiles show recognizable examples. A code row groups its value with copy and disable actions.

## Motion

Use the existing countdown and capture flash as feedback. Keep other transitions short and respect reduced motion.

## Accessibility

Use labeled controls, live status updates, and touch targets of at least 44 pixels for the kiosk. Keep both orientations usable and allow page reflow at smaller widths.

## Verification scope

Tablet layouts are checked in an emulated browser. Safari camera behavior and the physical print path require an iPad and printer.
